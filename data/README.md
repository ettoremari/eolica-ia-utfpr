# Dados

Manter dados brutos em `raw/` e dados derivados em `processed/`, com metadados. Não inserir dados pessoais, material confidencial ou dados institucionais sem autorização.

Para cada conjunto, documentar origem/licença, data de obtenção, cobertura temporal e espacial, unidade/frequência, instrumentos/calibração, limpeza/transformações e versão do código.
