# Diário de aprendizagem

Copiar `templates/REGISTRO_APRENDIZAGEM.md` para cada sessão. Usar ID `APR-AAAA-MM-DD-001`.

- Registrar confusão, esquecimento e erros.
- Separar explicação recebida de explicação produzida pelo participante.
- Encerrar cada tema com tarefa independente, quando apropriado.
- Não declarar competência com base apenas em leitura ou familiaridade.
- Vincular cada competência a evidência concreta.
